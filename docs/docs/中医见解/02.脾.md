# 脾

脾主运化，属土，土可以运化水分，也可以运化营养

所以脾可以运化人身体内的水，还有吃进去的食物中的营养

运即输送，化即消化



## 作用

### 运化水液（水湿代谢）

- 脾把喝进去的水，以及食物里的水分，**吸收、布散、排泄**到全身
- 清的部分 → 变成**津液**滋养全身
- 浊的部分 → 通过**肾、膀胱、肺、汗孔**排出体外

**"脾主为胃行其津液"**、**"脾为生痰之源"**（水液代谢失常 → 水湿、痰饮）。

**对应现代**：水盐代谢、淋巴循环、组织液平衡。





### 运化气血（生成气血的源头）

- 水谷精微 → 上输心肺 → **与呼吸之气结合 → 生成"气血"**
- 所以脾是 **"气血生化之源"、"后天之本"**

> 经典：**"脾为气血生化之源"**、**"中焦受气取汁，变化而赤，是谓血"**。

脾一虚 → 气血不足 → 面色萎黄、乏力、头晕、月经少。





### 运化营卫（更细分）

- **营气**：精微中"柔和、入脉"的部分 → 营养全身、化血
- **卫气**：精微中"剽悍、行于脉外"的部分 → 温养肌肤、防御外邪

> **"四季脾旺不受邪"**——卫气足，免疫力强，人就**不容易生病、不容易长胖**。







## 运化对象

| **运化对象** | **输入**     | **输出**    | **对应现代** | **脾虚表现**             |
| :----------: | :----------- | :---------- | :----------- | :----------------------- |
|   **水谷**   | 食物         | 水谷精微    | 消化吸收     | 没胃口、腹胀、便溏、消瘦 |
|   **水液**   | 水、食物水分 | 津液 + 排泄 | 水盐代谢     | 水肿、痰湿、舌胖有齿痕   |
|   **气血**   | 水谷精微     | 气、血      | 造血、营养   | 面色萎黄、乏力、月经少   |
|   **营卫**   | 精微         | 营气、卫气  | 免疫、体温   | 易感冒、自汗、虚胖       |



## 脾的重要性

**脾是"后天之本"**——人出生以后，全靠脾胃从食物中**"造血、补气、供能"**：

> 🔄 **食物 →（脾运化）→ 水谷精微 →（心肺）→ 气血 → 滋养全身**

所以：

- **脾好** → 吃嘛嘛香、气血足、肌肉壮、精力旺、免疫力强
- **脾虚** → 吃再多也不吸收、气血亏、人虚胖或消瘦、痰湿重、整天累

这也是为什么中医**调理身体，几乎都从"健脾"入手**。







## 脾的病症

> **《内经》："诸湿肿满，皆属于脾。"** —— 身体里凡是**湿气、水肿、胀满**的问题，根源都在脾。

脾一虚，就像**分拣中心停工**，会连锁引发两大类问题：

- **虚证**：脾自己"没力气"了（气虚→阳虚→气陷→不统血）
- **实证/虚实夹杂**：脾停工后**水液代谢不掉**，堆积成"湿→痰→饮"，反过来**困住脾**（恶性循环）





### 脾气虚证

最基础、最常见

- **原因**：饮食不节（暴饮暴食/饥饱不定/过食生冷肥甘）、思虑过度（思伤脾·思则气结）、久病劳倦
- **症状**：
  - 消化：**食少、食后腹胀尤甚**、大便溏薄（先干后稀）
  - 全身：**神疲乏力、少气懒言、肢体倦怠**
  - 形体：消瘦或虚胖
  - 面色：**萎黄**
  - 舌脉：舌淡胖有齿痕、苔白、脉缓弱
- **本质**：**脾气不足 → 运化水谷无力**。脾"干活没力气"，食物营养提取不下来——"纳少、腹胀、便溏"是标志三联征
- **治理**：**健脾益气**。
  - **方**：六君子汤/补中益气汤/参苓白术散。
  - **药**：党参、白术、茯苓、山药、莲子。
  - **中成药**：补中益气丸、参苓白术颗粒



### 脾阳虚证

气虚 + 怕冷，即"火力不够"

- **原因**：脾气虚日久伤阳、过食生冷寒凉、久病及肾（肾阳不足 → 脾阳无源）
- **症状**：在脾气虚基础上
  - 畏寒肢冷、怕冷、手脚冰凉
  - 腹中冷痛、喜温喜按
  - 大便稀溏甚至有未消化食物残渣
  - 全身浮肿
  - 白带量多质稀清冷
  - 舌淡胖、苔白滑、脉沉迟无力
- **本质**：**脾阳虚衰 → 失于温煦 + 水湿不化**。脾不仅没力气，还**缺"火力"**——所以既有消化差，又有明显寒象和水肿
- **治理**：**温阳健脾**。
  - **方**：理中丸（腹泻）、实脾饮（水肿）、完带汤（带下）。
  - **药**：干姜、附子、桂枝、白术、茯苓。
  - **食**：干姜花椒粥



### 脾虚气陷证

气虚的升级：升举无力 → 下垂

- **原因**：脾气虚日久、升举无力反而下陷（长期劳累、产后、久病）
- **症状**：脾气虚的症状再加如下
  - 脘腹坠胀、食后加重
  - 便意频繁、肛门坠胀、久泄脱肛
  - 内脏下垂：胃下垂、子宫脱垂、脱肛
  - 小便混浊如米汤
  - 头晕目眩
  - 舌淡、脉缓弱
- **本质**：**脾气亏虚 → 升举固摄无力**。脾主"升清"把内脏托住，气一陷 → 东西往下掉（下垂、脱肛、漏）
- **治理**：健脾益气、升阳举陷。方：补中益气汤（代表方，黄芪、升麻、柴胡升举）。艾灸加百会穴



### 脾不统血证

气虚到不能管住血

- **原因**：脾气虚极、**统摄无权**，血逸出脉外
- **症状**：
  - 各种慢性出血：便血、尿血、皮下紫癜、牙龈出血、鼻衄
  - 妇女月经过多、淋漓不尽
  - 伴脾气虚表现：食少、腹胀、便溏、面色无华、神疲乏力
  - 舌淡、脉细弱
- **本质**：脾气虚弱 → 统血失常。脾是"血的管家"，管家没力气 → 血到处乱跑（各种慢性出血）
- **治理**：**健脾益气摄血**。
  - **方**：**归脾汤**（代表方，人参、黄芪、白术、当归）。
  - **中成药**：归脾丸



### 脾虚湿盛证

脾虚湿困证 / 脾虚湿盛证（虚 + 湿并重，最常见日常状态）

- **原因**：饮食不节、思虑过度伤脾、久坐少动、先天脾虚，脾虚为本 + 外湿入侵（久居潮湿或者游泳）、饮食肥甘生冷 → 水液停聚成湿

- **症状**：
  - 腹胀、口黏腻、口中发甜
  - 没胃口
  - 纳呆、泛酸恶心
  - 头昏沉、四肢困重（像裹湿布）
  - 面色发黄晦暗
  - 大便溏泄不爽、小便短少
  - 舌头胖大有齿痕、苔白腻、脉濡缓
- **本质**：脾气虚 → 运化不了水湿 → 湿气泛滥
- **治理**：**健脾化湿（虚实同治）**。
  - **方**：**参苓白术散**（千古名方，脾虚湿盛首选）+ 藿香正气散。
  - **食**：薏苡仁、山药、芡实、莲子、白扁豆



### 脾阳虚湿盛

- **本质**：脾虚 + 阳虚（比上面更严重）
- **表现**：上面所有症状 + 怕冷、手脚凉、吃凉的就拉肚子
- **原因**：长期脾虚没管 → 阳也伤了；或过食生冷



### 脾虚湿困（困脾）

- **本质**：湿气反过来把脾"困住"了，脾更转不动
- **表现**：极度困倦、像睡不醒、身体沉重、肚子胀
- **原因**：梅雨季/回南天外湿重 + 本身脾虚





### 寒湿困脾证

**实邪为主**，外感寒湿 + 脾阳被"冻住"

- **原因**：外感寒湿（久居寒湿环境、淋雨涉水）+ 过食生冷 → 寒+湿困阻脾阳（起病较急、症状较重）
- **症状**：
  - 脘腹胀闷、腹痛泄泻
  - **口腻、不渴**（关键：寒湿不伤津所以不渴）
  - 头身困重
  - **肢体浮肿**
  - **身目发黄、黄色晦暗如烟熏**（阴黄）
  - 白带量多清稀
  - 舌淡胖、**苔白腻/白滑**、脉濡缓
- **本质**：寒湿邪气困阻脾阳 → 运化被"冻住"。和"脾虚湿困"的区别：本证以实邪（寒湿）为主、起病急；脾虚湿困以虚（脾虚）为本、病程长
- **治理**：**温脾化湿**。
  - **方**：藿香正气散。**外治**：**艾灸神阙（隔盐灸/隔姜灸）**极有效。
  - **食**：薏苡仁、山药、芡实



### 湿热蕴脾证

- **原因**：外感暑湿/湿热之邪、过食肥甘辛辣醇酒、熬夜 → 湿郁化热
- **症状**：
  - 脘腹胀闷、恶心欲呕
  - **口中黏腻、口苦**、口渴不多饮
  - **大便溏泄不爽（黏腻挂马桶）**
  - 小便短黄
  - **身热不扬、汗出热不解**
  - **皮肤发黄、黄色鲜明如橘子（阳黄）**、皮肤瘙痒、皮肤油腻长痘
  - 舌红、**苔黄腻**、脉濡数
- **本质**：湿热蕴结脾胃、气机受阻。和寒湿的区别：有热象——口苦、尿黄、苔黄腻、身热
- **治理**：清热祛湿、化湿和中。
  - 方：茵陈蒿汤/连朴饮。注意：忌用温补（和寒湿相反）



### 痰湿中阻证

湿的"浓缩升级版" = 痰

- **原因**：湿聚日久成痰、停于中焦（过食肥甘甜腻、饮酒、情志内伤气滞）
- **症状**：
  - 头重如裹、眩晕（清阳不升）
  - 脘腹痞闷、呕恶
  - 口淡、不渴
  - **咳嗽、痰白清稀**
  - 四肢麻木
  - 舌苔白厚腻、脉滑
- **本质**：**湿聚成痰、痞阻中焦 → 清阳不升、浊阴不降**。湿是"稀的"，痰是"浓的"——**痰比湿更重、更易引发怪病**（"怪病多痰"）
- **治理**：燥湿化痰、理气和中。
  - 方：平胃散合二陈汤（苍术、厚朴、陈皮、半夏、茯苓）。原则：治痰先治气



### 湿热下注

- **本质**：湿热往下走，堵在下焦
- **表现**：小便黄赤、大便黏、白带黄/阴囊潮湿、下肢湿疹脚气、下巴长痘
- **原因**：上面刚详细讲过，久坐、憋尿、吃辣喝酒、熬夜



### 湿阻中焦

- **本质**：湿气堵在脾胃这个"中间枢纽"
- **表现**：胃胀、没食欲、打嗝、恶心、大便不成形
- **原因**：饮食不节、暴饮暴食、脾虚



### 湿困上焦

- **本质**：湿气往上走，蒙住头面
- **表现**：头昏沉像裹了湿布、胸闷、嗜睡、眼皮肿
- **原因**：脾虚生湿上泛、淋雨涉水后外湿入侵



### 风湿袭表

外湿+风邪

- **本质**：外界湿气+风邪侵入体表
- **表现**：关节酸痛沉重（尤其下雨天加重）、肌肉酸重、皮肤湿疹
- **原因**：淋雨、住潮湿环境、穿湿衣服、长期涉水



### 痰湿阻肺

- **本质**：湿气凝聚成痰，堵在肺里
- **表现**：咳嗽痰多（白痰黏痰）、胸闷、嗓子总有痰
- **原因**：脾虚生痰→上输于肺（脾为生痰之源，肺为贮痰之器）



### 痰湿蒙窍

- **本质**：痰湿堵在头部清窍
- **表现**：头晕目眩、记忆力差、嗜睡、甚至昏蒙
- **原因**：脾虚痰湿重 + 长期熬夜/压力大



### 痰瘀互结

- **本质**：痰湿 + 血瘀搅在一起
- **表现**：长硬块（甲状腺结节、乳腺增生、子宫肌瘤）、面色暗沉
- **原因**：痰湿长期不化 → 阻滞气血 → 形成瘀血



### 水肿（脾失健运，水溢肌肤）

- **原因**：脾虚 → 水液运化无力 → 水停溢于肌肤（"诸湿肿满皆属于脾"）
- **症状**：**腰以下水肿尤甚、按之凹陷不起**、腹胀、纳少、乏力、小便少、舌淡苔白腻、脉沉缓
- **本质**：脾阳虚不能运化水湿 → 水钠潴留（对应现代：心衰、肾炎、营养不良性水肿）
- **治理**：温阳健脾、行气利水。
  - 方：实脾饮 / 真武汤（肾阳虚为主时）。
  - 食：薏苡仁、冬瓜、赤小豆



### 泄泻（腹泻，"泄不离脾"）

- **原因**：脾虚 → 水谷不化 → 清浊不分、水走大肠（饮食生冷、情志、感染诱发）
- **症状**：大便溏薄/次数多/水样、肠鸣、腹胀、食少、完谷不化，久泻致脱肛
- **本质**：**脾虚升清失职、水谷下注**——"脾虚则清阳不升，清阳不升则生飧泄"
- **治理**：参苓白术散（脾虚湿盛型腹泻首选）；久泻及肾加附子理中丸



### 带下病（妇科，脾虚湿注下焦）

- **原因**：脾虚 → 湿气下注 → 带脉失约
- **症状**：带下量多、色白或淡黄、质黏稠清稀、无臭、绵绵不断 + 面色萎黄、乏力、纳少
- **本质**：**脾虚湿困、带脉不固**——湿浊从下窍而出
- **治理**：**完带汤 / 参苓白术散**（脾虚湿困型带下代表方）



### 痰饮 / 咳喘（脾为生痰之源 → 肺，"培土生金"）

- **原因**：脾虚生痰 → 上贮于肺 → 咳喘痰多（"脾为生痰之源，肺为贮痰之器"）
- **症状**：**反复发作的慢性咳嗽、痰多色白**、久咳不愈、食少乏力、舌淡苔白腻
- **本质**：脾虚痰浊上犯于肺——所以**治痰嗽光止咳无效，必须从脾治**
- **治理**：**参苓白术散合二陈汤**（培土生金）；老年慢性支气管炎尤其适用







### 肾阳虚水泛

- **本质**：肾阳不足 → 水液代谢不了 → 全身浮肿
- **表现**：腰以下浮肿明显、怕冷、小便少、腰酸
- **原因**：久病伤肾、年老肾亏、长期过劳



### 肝胆湿热

- **本质**：湿热堵在肝胆
- **表现**：口苦、胁肋胀痛、眼睛黄/皮肤黄、脾气暴躁、女性带下黄/男性阴囊潮湿
- **原因**：喝酒多、情绪压抑化火、过食油腻



### 膀胱湿热

- **本质**：湿热堵在膀胱
- **表现**：尿频尿急尿痛、小便黄赤
- **原因**：喝水少、憋尿、外感湿热



### 大肠湿热

- **本质**：湿热堵在大肠
- **表现**：腹痛腹泻、大便黏臭、肛门灼热、痢疾
- **原因**：吃了不干净/太辣太油的东西



### 外湿侵袭

- **本质**：外界湿邪从皮肤毛孔进入
- **表现**：关节沉重酸痛、肌肉酸重、皮肤湿疹、头重如裹
- **原因**：淋雨、涉水、居住环境潮湿、穿未干的衣服



### 暑湿困脾（夏天专属）

- **本质**：夏天暑热 + 湿气一起伤脾
- **表现**：夏天特别困、没胃口、胸闷恶心、发热不高但缠绵不退
- **原因**：暑天贪凉饮冷 + 湿气重



## 核心逻辑

① 恶性循环：脾虚 ↔ 湿困

> **脾虚 → 生湿 → 湿困脾 → 脾更虚**。所以治湿**必须健脾**，否则"千寒易去，一湿难除"——这就是参苓白术散"**补脾 + 祛湿**"并行的道理。

② 发展链条：气 → 阳 → 陷 → 不统血

> 脾气虚（轻）→ 发展 → 脾阳虚（怕冷）→ 再发展 → 气陷（下垂）/ 不统血（出血）。**早治在"气虚"阶段最好**。

③ 湿的浓缩链：水 → 湿 → 痰 → 饮

> 程度递进：**水（稀）→ 湿（困脾）→ 痰（中阻）→ 饮（停聚）**。"脾为生痰之源"贯穿全程。

| 吃太多生冷（冰饮、冰淇淋、生食）    | 寒湿困脾、脾阳虚   |
| 吃太多油腻、甜食、奶制品            | 湿热蕴脾、痰湿内蕴 |
| 喝酒（尤其啤酒）                    | 湿热下注、肝胆湿热 |
| 暴饮暴食、饮食不规律                | 脾虚湿盛、湿阻中焦 |
| 喝水太多/喝太快（超出脾的运化能力） | 水湿内停           |



### 生活习惯类

| 原因            | 导致的湿证             |
| --------------- | ---------------------- |
| 久坐不动        | 湿热下注、脾虚湿盛     |
| 长期熬夜        | 阴虚生热 + 湿 → 湿热   |
| 憋尿/憋便       | 湿热下注（膀胱、大肠） |
| 缺乏出汗        | 湿气排不出去，累积     |
| 思虑过度/压力大 | 思伤脾 → 脾虚生湿      |



### 环境类

| 原因                                   | 导致的湿证              |
| -------------------------------------- | ----------------------- |
| 住潮湿环境（地下室、一楼、南方回南天） | 外湿侵袭 → 风湿、湿困脾 |
| 淋雨、涉水、穿湿衣服                   | 外湿侵袭                |
| 夏天吹空调+吃冷饮                      | 暑湿困脾、寒湿困脾      |



### 体质/病理类

| 原因          | 导致的湿证                 |
| ------------- | -------------------------- |
| 先天脾虚体质  | 脾虚湿盛（一生都容易湿重） |
| 年老体衰      | 肾阳虚水泛、脾虚湿盛       |
| 久病不愈      | 脾虚 → 湿重 → 加重病       |

## 舌头与脾





### 舌头裂纹

当舌头的中间有裂纹时，通常是脾胃的问题

- **裂纹在舌中 + 舌质淡 + 齿痕** → 脾虚气血不足，舌头中间这片"脾区"失养
- **裂纹在舌中 + 苔黄腻** → 脾胃湿热，湿热灼伤胃阴，舌面裂开
- **裂纹在舌中 + 苔少/无苔 + 舌红** → 胃阴虚，脾胃阴液亏耗
- **舌中有深沟/一条竖裂纹** → 传统说法叫"脾虚舌"，提示脾胃功能长期偏弱
