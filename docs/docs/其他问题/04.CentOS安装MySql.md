# CentOS安装MySql

本次是`CentOS8.1.1911`安装`Mysql8`





## 卸载MariaDB

`MariaDB`是CentOS 8 默认自带，避免冲突

查看是否已安装

```bash
rpm -qa | grep mariadb
```

如果没有任何输出，说明系统未安装 MariaDB

如果有输出结果，例如`mariadb-server-10.5.9-1.el7.x86_64`，就要进行删除

```bash
sudo dnf remove mariadb* -y
```

最后输出`Complete!`即删除成功



## 切换vault源

先备份原来的源

```bash
sudo mkdir -p /etc/yum.repos.d/backup
sudo mv /etc/yum.repos.d/CentOS-*.repo /etc/yum.repos.d/backup/
```

切换阿里vault源

```bash
sudo curl -o /etc/yum.repos.d/CentOS-Base.repo \
https://mirrors.aliyun.com/repo/Centos-vault-8.5.2111.repo
```

清理缓存并重新生成

```bash
sudo dnf clean all
sudo dnf makecache
```

如果看到类似下面输出，说明源已经恢复正常：

```bash
Metadata cache created.
```



:::tip 如果不切换源可能会报以下错误

```txt
download metadata for repo 'AppStream'
Error: Failed to download metadata for repo 'AppStream'
```

因为而是 **CentOS 8 已于 2021-12-31 停止官方维护**，默认的 `AppStream`/ `BaseOS`仓库地址（`mirror.centos.org`）已经下线，`dnf`拉不到元数据就会报这个错。

:::



## 安装MySQL仓库

```bash
sudo dnf install https://dev.mysql.com/get/mysql80-community-release-el8-9.noarch.rpm -y
```

若输出`Complete!`即安装成功



确认仓库已启用

```bash
dnf repolist enabled | grep mysql
```

为以下结果即正常

![image-20260718101558468](https://gitee.com/xarzhi/picture/raw/master/img/image-20260718101558468.png)

如果没有`mysql80-community`这一项，需要手动开启

```bash
sudo dnf config-manager --enable mysql80-community
```

**避免模块残留，先 reset 再 disable**

```
sudo dnf module reset mysql
sudo dnf module disable mysql -y
```


直接粘贴或者输入，有的终端粘贴不了，手动输入就很难受了

![image-20260718103152490](https://gitee.com/xarzhi/picture/raw/master/img/image-20260718103152490.png)

## 开启远程连接

开启远程连接之后，我们就可以使用`navicat`或者`winscp`这种工具连接数据库了

执行以下指令开启sql语句书写模式

```bash
mysql -u root -p
```

然后输入如下sql语句

注意要把羡慕两个强密码处修改为刚才设置的密码

```sql
ALTER USER 'root'@'localhost' IDENTIFIED BY '你的强密码';
CREATE USER 'root'@'%' IDENTIFIED BY '你的强密码';
GRANT ALL PRIVILEGES ON *.* TO 'root'@'%' WITH GRANT OPTION;
FLUSH PRIVILEGES;
EXIT;
```

:::tip sql说明

修改本地 root 密码

```sql
ALTER USER 'root'@'localhost' IDENTIFIED BY '你的强密码';
```

创建远程 root 用户

```sql
CREATE USER 'root'@'%' IDENTIFIED BY '你的强密码';
```

授予全部权限

```sql
GRANT ALL PRIVILEGES ON *.* TO 'root'@'%' WITH GRANT OPTION;
```

刷新权限缓存

```sql
FLUSH PRIVILEGES;
```

 退出

```sql
EXIT;
```

:::

如果看到都是`Query OK`就行

![image-20260718104508973](https://gitee.com/xarzhi/picture/raw/master/img/image-20260718104508973.png)





然后修改配置文件

```bash
sudo vi /etc/my.cnf
```

按i进入编辑模式，然后确认或者添加如下内容

```txt
bind-address=0.0.0.0
```

![image-20260718104740880](https://gitee.com/xarzhi/picture/raw/master/img/image-20260718104740880.png)

然后退出编辑：按`ESC`，输入`:wq`然后回车

接下来重启mysql

```bash
sudo systemctl restart mysqld
```

防火墙放行3306

```bash
sudo firewall-cmd --permanent --add-port=3306/tcp
sudo firewall-cmd --reload
```

看到输出`success`即为成功
