# svg标签

svg使用xml格式的标签来绘制图形







### 在 HTML 中嵌入 SVG 的 4 种方式

| 方式     | 写法                    | 优点                   | 缺点                             | 适用                     |
| -------- | ----------------------- | ---------------------- | -------------------------------- | ------------------------ |
| 内联     | 直接写 `<svg>`          | 全 CSS/JS 控制、可交互 | HTML 体积大、难缓存              | 图标系统、图表、交互动效 |
| img      | `<img src="a.svg">`     | 简单、可缓存           | 内部 DOM 不可见、不能改色/绑事件 | 静态装饰图               |
| object   | `<object data="a.svg">` | 独立文档、内部 JS 可跑 | 跨域受限、父页 CSS 难穿透        | 独立复杂图形             |
| CSS 背景 | `background:url(a.svg)` | 排布方便               | 无 DOM、无无障碍                 | 纹理、装饰               |
