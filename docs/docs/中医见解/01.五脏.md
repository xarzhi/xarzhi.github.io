## 五脏六腑

五脏指的是**心、肝、脾、肺、肾**五个系统。六腑指的是**大肠、小肠、胃、胆、膀胱、三焦**六个系统。

脏和腑是根据内脏器官的功能不同而加以区分的：

- **脏**：主要是指胸腹腔中**内部组织充实**的一些器官，主要是储藏精气，精气则是能充养脏腑，是维持生命活动不可或缺的物质。
- **腑**：是胸腹腔中一些中**有空腔**的器官，它们具有消化食物、吸收营养、排泄垃圾的功能。

五脏与六腑的关系，实际上就是阴阳表里关系。**脏属阴，腑属阳**，脏为里，腑为表，一脏一腑，一阴一阳，一表一里相互配合，从而构成了脏腑之间的密切联系。



## 五脏与五季

### 春季养肝

肝：春季肝气最旺，主导着整个人体。如果这个时间不护好肝，让它“过度劳累”，就可能导致肝气克伐太过，导致肝气无力升发而郁滞，进一步引起脾胃功能受损或情绪郁结等症。



春养肝，指春季应当养肝。**春天在五行中属本木，而人体的五脏之中肝也是属木性**，因而春气通肝。在春天，肝气旺盛而升发，中医认为，春天是肝旺之时。趁势养肝可以避免暑期的限虚，而过于补肝又肝火过旺，如果肝气升发太过或是肝气郁结，都易损伤肝脏。春季养肝应该多吃凉性食品像粥类、茶类、水果等都很不错。因此。春季养生又为注重精神调理，保持心胸开阔，情绪乐观。以使肝气顺达，气血调畅，达到防病保健之目的。



### 夏季养心

夏季心气最旺，是身体的主宰，所以夏季更要注意心脏的养生保健。心主神明，心气旺则神清气爽，如果心火太过，则火热之邪容易导致皮肤疮疡等疾病。



中医认为：春夏养阳，秋冬养阴，养生之道一定要遵循规律：而心脏是人体生命活动的主率。心脏主阳气。主血脉、主心智：所以夏季养心当时，可事半功倍，所谓红色养心，在所有红色的果蔬当中，名声最好的莫过于苹果。民间有一天一苹果，医生远离我的说法。苹果性温和，含有各种维生素和微量元素，是所有的水果中最接近完美的一种。营养学家认为：红色蔬果最典型的优势在于它们都是富含天然铁质的食物，例如我们常吃的樱桃、大枣等都是贫血患者的天然良药此外还有红豆、红皮花生、红糖、胡萝卜、西红柿、山楂、红辣椒、西瓜、瘦肉（牛肉，兔肉等）、石榴、水蜜桃等等。



### 长夏养脾

脾：长夏时节应于脾气。脾一方面主持着水谷的运化，另一方面控制着人体的肌肉四肢。如果脾被过度使用，很容易出现食欲不振、腹胀、腹泻等，而倦怠、乏力等症状，也多由脾气被湿热所困所致。



长夏时值夏、秋之际,兴平天气，天热下降，低湿上蒸，湿热相缠，内应脾脏，应采用赤小豆、绿豆、藿香等淡渗之品，利湿健脾以达到气血生化有源。



### 秋季养肺

肺：秋季为肺所主，到了秋季，肺脏最累也最容易受外邪所伤。肺主呼吸之气，这个时候感冒、支气管哮喘、慢性支气管炎等呼吸系统疾病往往大量增加，需要格外注意呵护。



按中医的五行学说，肺属金，秋天正是肺的脏气最旺，功能最强的时候，我们可以借天时以养肺，肺在中医理论当中，主要有两大功能，一个是宣发，一个是肃降。

- 宣发主要是通过发汗、咳嗽、流涕来表现。
- 肃降功能主要表现在两个方面，一是通调水道，下输膀胱；二是推肠道，排泄糟柏。但肃降的功能通常要从病理状态中才能感知到，正所谓“善者不可得见，恶乃可见”。

也就是说它的功能正常时，你根本看不到它的作用，但不正常了，才会有症状表现出来。许多便秘患者并不是大便干硬，而是大便无力下行。还有人小便难流，需良久方出，这些都与肺不肃降有直接关系。



### 冬季养肾

肾：肾为“先天之根”，在人体代表着生命之气，凡生殖、发育均由肾所主。如果此时不注意给五脏“减负”，让它们跟着自然界“冬眠”，就很容易使阳气郁闭不通，引起气血阻滞，导致手足发冷、四肢疼痛。



冬季养肾正当时！冬天是人体阳气生理机能潜藏的时候，而肾脏的主要功能就是“养藏”。此时，肾脏就要为维持冬季热能支出而准备足够的能量，又要为来年“春温春生“积蓄力量。以提高肌体的防疫功能和抗病能力，减少疾病的发生和发展。如果肾被冬天的寒气损伤，容易发生腰膝冷痛，易感风寒，夜尿频多，咽干口燥，头晕耳鸣、内分泌功能紊乱，免疫功能低下，怕冷等症状，还可能影响其它脏腑器的生理机能。





## 五脏与五行

五脏也分别代表五行

- 心主火
- 肝主木
- 脾主土
- 肺主金
- 肾主水



依据五行相克规律，脏腑之间有相互制约的关系，如

- 肺气肃降，气机调畅，可以抑制肝气之上逆和肝阳之上亢，此即金克木；
- 肝气的条达，可以疏泄脾湿之壅滞，此即木克土；
- 脾气运化，可以调节肾主水功能，以防止水湿之泛滥，此即土克水；
- 肾水的滋润，上济于心，以制约心火的亢炎，此即水克火；
- 心之阳热，可以制约肺气的清肃太过，此即火克金。





顺位生，意即金生水，水生木，木生火，火生土，土生金。

隔位克，意即金克木，水克火，木克土，火克金，土克水。





## 五脏与五色

“五色入五脏”理论最早出自中医经典著作《黄帝内经》，其中记载到——色味当五藏：

- 白当肺，味辛
- 赤当心，味苦
- 青当肝，味酸
- 黄当脾，味甘
- 黑当肾、味咸。



### 白色润肺

肺属金，白色和辛味入肺。中医认为，辛入肺，可发散、行气、活血，辛味能刺激胃肠蠕动，增加消化液的分泌，还能促进血液循环和机体代谢，可祛风散寒、解表止痛。

常见的白色食物有，豆腐、冬瓜、梨、白萝卜、 藕、百合。



### 红色补心

心属火，红色和苦味入心。增强血液循环、促使神经系统兴奋的作用，不仅有助于养心，还可以起到减轻疲劳、补血、祛寒等作用。

常见的红色食物有，红豆、红薯、胡萝卜、山楂、红枣等



### 绿色养肝

肝属木，青（绿）色和酸味入肝。绿色可调节体内平衡，消除紧张情绪，起镇静作用，有助于减轻头痛、发热、晕厥失眠。

常见的绿色食物有，菠菜、油菜、空心菜、黄瓜、丝瓜、苦瓜、西兰花、青辣椒、绿豆等。





### 黄色益脾

脾属土，黄色和甜味入脾。黄色具有刺激神经和消化系统，加强逻辑思维的作用。常见的黄色食物有：薏米、南瓜、黄豆、柑橘、香蕉、菠萝等。





### 黑色补肾

肾属水，黑色和咸味入肾；咸味能软坚润下，调节水盐代谢，可增强体力和食欲。 常见的黑色食物有，黑豆、黑米、黑芝麻、桑葚、紫菜、黑木耳、海带等。





## 五脏与五味

**五味**指的是药物或食物所具有的**辛、甘、酸、苦、咸**五种不同的味道，如果食用某一种味道过多的话就会导致我们人体某一个脏腑功能出现偏盛或偏衰的状态。

中医认为，**酸入肝、咸入肾、苦入心、辛入肺、甘入脾**，少食可以补养对应的内脏，但五味不均衡、五味太过则会伤及五脏。



:::tip

**注意**：这些味道是对相应的脏器比较好，但是吃多了也会有害，适量即可，最好是五味搭配

:::



### 酸入肝

酸味食物有增强消化功能和保护肝脏的作用。常吃不仅可以帮助消化，杀灭胃肠道内的饿病菌，还有防感冒、降血压、软化血管之功效。以酸味为主的酸梅、石榴、西红柿、山楂、橙子，均含有维生素C，可防癌、抗衰老、防治动脉硬化。



### 苦入心

古有良药苦口之说，中医认为苦味食物能泄、能燥、能坚阴，具有除湿和利尿的作用。像橘皮、苦杏仁、苦瓜、百合等，常吃能防止毒素的积累，防治各种疮症。



### 甘入脾

性甘的食物可以补养气血、补充热量、解除疲劳、调胃解毒，还具有缓解痉挛等作用。如红糖、桂圆肉、蜂蜜、米面食品等，都是补甘食物的不错选选择。



### 辛入肺

中医认为辛味食物有发汗、理气之功效。人们常吃的葱、姜、蒜、辣椒、胡椒，均是以辛味为主的食物，这些食物既能保护血管，有可调理气血、疏通经络的作用，经常食用，可预防风寒感冒，但患有痔疮便秘、肾经衰弱者不可食用。



### 咸入肾

咸为五味之冠，百吃不厌。中医认为咸味食物有调节人体细胞和血液渗透、保持正常代谢的功效。咸味有泄下、软坚、散结和补益阴血等作用。如盐、海带、紫菜、海蜇等属于优质的咸味食品。





:::tip warning

但是，在选择食物时，必须五味调和，这样才有利于健康。若五味过偏，会引起疾病的发生。如：

- 酸味太过容易造成肝气太旺而克制脾胃功能（木克土）；
- 苦味太过又很容易造成心火太旺而克制肺气（火克金）；
- 甘味太过很容易造成脾胃过旺而克制肾气（土克水）；
- 辛味太过容易造成肺气过盛而克制肝气（金克木）；
- 咸味过多很容易造成肾气过盛而克制心气（水克火）。

:::



> 《黄帝内经》中对于五味和五脏的关系是这样写的：
>
> 
>
> 【原文】
>
> 心之合（1）脉也，其荣（2）色也，其主（3）肾也。肺之合皮也，其荣毛也，其主心也。肝之合筋也，其荣爪也，其主肺也。脾之合肉也，其荣唇也，其主肝也。肾之合骨也，其荣发也，其主脾也。
>
> 是故多食咸，则脉凝泣（4）而变色；多食苦，则皮槁而毛拔（5）；多食辛，则筋急（6）而爪枯；多食酸，则肉胝而唇揭（7）；多食甘，则骨痛而发落，此五味之所伤也。故心欲苦，肺欲辛，肝欲酸，脾欲甘，肾欲咸，此五味之所合五脏之气也。
>
> 
>
> 【注释】
>
> （1）合：配合，指脏腑与组织相配合。
>
> （2）荣：荣华，指脏腑精气外荣。
>
> （3）主：克制之意。
>
> （4）凝泣：泣，同“涩”。凝泣，即是凝结而不通畅的意思。
>
> （5）拔：除也，有脱落之意。
>
> （6）急：拘挛。
>
> （7）肉胝（zhī）而唇揭：指肉厚并且唇缩。
>
> 
>
> 【详解】
>
> - 与心脏相配合的是脉，它的荣华表现于面部，而克制心的是肾。
> - 与肺脏相配合的是皮，它的荣华表现于毛，克制肺的是心。
> - 与肝脏相配合的是筋，它的荣华表现在爪甲，克制肝的是肺。
> - 与脾脏相配合的是肉，它的荣华表现于唇，克制脾的是肝。
> - 与肾脏相配合的是骨，它的荣华表现于发，克制肾脏的是脾。
>
> 
>
> - 所以多吃咸味的东西，会使血脉凝滞，而面色失去光泽；
> - 多吃苦味的东西，会使皮肤干燥而毫毛脱落；
> - 多吃辛味的东西，会使筋脉拘挛而爪甲枯槁；
> - 多吃酸味的东西，会使肉坚厚而唇缩；
> - 多吃甜味的东西，会使骨骼疼痛而头发脱落。
>
> 这些都是由于饮食五味的偏嗜而受到伤害的情况。所以心喜苦味，肺喜辛味，肝喜酸味，脾喜甘味，肾喜咸味，这就是五味和五脏的对应关系。





## 五脏与五官

人的五官与五脏也有直接联系：肝开窍于目，心开窍于舌，脾开窍于口，肺开窍于鼻，肾开窍于耳。

- 心主血气，藏神，五行属火，充于脉，其华荣于面，开窍于舌，与小肠互为表里，色红，味苦，嗅焦； 心有病者，舌尖红，或舌头转动不灵，吐字不清。
- 肝主疏泄，藏魂，五行属木，充于筋，其华荣于爪，开窍于目，与胆互为表里，色青，味酸，嗅臊； 肝有病者，眼中必有病象，如眼黄，眼涩，畏光，流泪。
- 脾主运化，藏意，五行属土，充于肌，其华荣于唇，开窍于口，与胃互为表里，色黄，味甘，嗅香；脾有病者，必口中乏味，食而不化，唇干裂。
- 肺主宣降，藏魄，五行属金，充于皮，其华荣于毛，开窍于鼻，与大肠互为表里，色白，味辛，嗅腥； 肺有病者，会出现鼻塞，流涕，打喷嚏，流鼻血，不辨香臭。
- 肾主精髓，藏志，五行属水，充于骨，其华荣于发，开窍于耳，与膀胱互为表里，色黑，味咸，嗅腐。肾有病者，耳中蝉鸣，或痒，或背，或聋。

## 五脏与五情

中医古籍对情绪和脏腑有如下记载：“怒伤肝、喜伤心、忧伤肺、思伤脾、恐伤肾”，人体五脏失调会引起不同情绪反应，反之，情绪又会影响五脏。所以保护身体，不狂喜、不大悲、不嗔怒、不惊不忧不恐，可以从懂得原理开始。



### 喜伤心

“过喜”或“暴喜”会使心气消耗过度。



### 怒伤肝

“盛怒”、“暴怒” 会导致肝气亢奋，过度消耗肝血，使肝血不足，则出现阳亢而阴不足的病理状态。“怒则气上”，气过升而不降，使气机升降失衡，也会影响到肝及其他脏的功能。



### 忧伤肺

愁忧、情绪抑郁导致肺气闭塞。忧愁的刺激量过大，或持续时间过长，就会使气机闭塞而致病。



### 思伤脾

是指思维长时间的高度集中，思虑太过。气血受阻，郁结在一处，不能通畅运行到周身而致病。

"思"**精准拆开**——它**不是泛指一切思考**，而是特指某几种**过度、停不下来、结住不动**的心理状态。



:::tip 伤脾的"思"，具体是这 5 类事

**百思不得其解（钻牛角尖）**

- 一件事怎么想都想不通，却**停不下来**
- "遇到百思不得其解的事，最好别去解，顺其自然"——这是经典建议

**所思不遂 / 求而不得（执念、思慕）**

- 想要的东西得不到、想见的人见不到、心愿未了
- 经典医案：女子婚后丈夫外出两年不归，"思男子不得，气结于脾"而绝食——**这就是典型的"思"**

**忧思牵挂 / 过度操心（心里放不下）**

- 操心家人、孩子、工作、人际关系，**永远有操不完的心**
- 对应现代人：家庭主妇、管理者、创业者

**谋虑怫逆 / 反复复盘（精神内耗）**

- 决策压力大、反复推演、自我怀疑
- 典型场景：睡前反复复盘白天细节，"我要是那样说就好了…"

**空怀妄想 / 长期担忧（焦虑、灾难化联想）**

- 还没发生就往坏处想，持续焦虑
- 现代对应：**广泛性焦虑、抑郁**——"思虑伤脾证"常见于抑郁症

**共同点只有一个**：**气机"结"住了**——想的事**反复回旋、无法放下、没有出口**。

:::



:::tip  为什么这种"思"偏偏伤脾？

| 环节             | 机制                                                      |
| ---------------- | --------------------------------------------------------- |
| **思则气结**     | 注意力过度凝聚 → 中焦气机停滞                             |
| **脾失健运**     | 脾主运化靠气机"动"→ 气一结，消化就停 → 没胃口、腹胀、便溏 |
| **气血生化不足** | 脾为后天之本 → 气血亏 → 面色萎黄、乏力、失眠              |
| **恶性循环**     | 脾越虚 → 越焦虑 → 越想 → 气越结                           |

:::





### 恐伤肾

惊恐不是直接伤肾，而是先通过心的感受，继而由肾承受。前者多伤及心神，后者则多伤肾气。
