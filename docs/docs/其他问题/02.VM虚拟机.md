## 3.下载系统镜像

安装好虚拟机后，不是就可以直接使用了，还要下载我们需要的系统镜像，一般是个ios文件

1. 微软官方下载渠道：获取原版镜像，安全性最高。

   - Windows 11：[微软官网](https://www.microsoft.com/zh-cn/software-download/windows11)

   - Windows 10：[微软官网](https://www.microsoft.com/zh-cn/software-download/windows10)
   - CentOs：[Download - The CentOS Project](https://www.centos.org/download/)

2. MSDN 我告诉你（ITellyou）：国内权威镜像索引，更新快，资源全。

   - 新站：[next.itellyou.cn](https://next.itellyou.cn/)

   - 备用站：[msdn.itellyou.cn](https://msdn.itellyou.cn/)

3. 系统库（xitongku.com）：致力于原版 Windows 生态服务，提供版本追踪与下载。

   - 下载：[www.xitongku.com](https://www.xitongku.com/index.html)

4. WinNew（winnew.cn）：从微软服务器获取最新的原版 Windows 镜像。

   - **下载**：[winnew.cn](https://winnew.cn/)



:::tip

下载好的镜像最好保存到一个记得住的位置，以后有可能还会下载其他的镜像

都保存在一起好一些，比我在D盘创建了一个`vm-ios`的文件夹，存放这些镜像

![image-20260714141325648](https://gitee.com/xarzhi/picture/raw/master/img/image-20260714141325648.png)

:::
