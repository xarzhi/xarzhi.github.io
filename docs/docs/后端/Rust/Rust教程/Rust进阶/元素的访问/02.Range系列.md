# Range系列

`Range`是一种语法，也是`std::ops`里的一系列结构体

| **语法** | **对应的 Struct**  | **含义**          |
| :------- | :----------------- | :---------------- |
| `a..b`   | `Range`            | `[a, b)`左闭右开  |
| `a..=b`  | `RangeInclusive`   | `[a, b]`全闭区间  |
| `a..`    | `RangeFrom`        | `[a, ∞)`          |
| `..b`    | `RangeTo`          | `(-∞, b)`         |
| `..=b`   | `RangeToInclusive` | `(-∞, b]`         |
| `..`     | `RangeFull`        | `(-∞, ∞)`整个范围 |

通过以上这些语法，可以在数组，切片，vec，字符串中提取若干个连续的元素

```rust
fn main() {
    let arr = [1, 2, 3, 4, 5];

    println!("{:?}", &arr[0..5]); // [1, 2, 3, 4, 5]

    let v = vec![1, 2, 3, 4, 5];
    println!("{:?}", &v[0..]); // [1, 2, 3, 4, 5]

    let str = "123456";
    println!("{:?}", &str[..str.len()]); // "123456"
}
```

这些类型能使用`[]`访问元素，是因为他们都实现了`Index`这个`Trait`

而`Index`里的`index()`方法，会根据`[]`中参数的类型，返回相应的切片

- 比如`arr[0..5]`就是实现的`Index<Range<usize>>`这个`trait`
- `v[0..]`就是实现了`Index<RangeFrom<usize>>`这个`Trait`
