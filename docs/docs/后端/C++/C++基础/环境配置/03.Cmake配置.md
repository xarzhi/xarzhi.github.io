# CMake环境配置

## 1.cmake是什么

**CMake 是一个开源的、跨平台的自动化构建系统生成工具**。它本身不直接构建软件，而是根据一个名为 `CMakeLists.txt` 的配置文件，为你的开发环境（如 Visual Studio, Xcode, Ninja, Makefiles 等）生成对应的构建文件。

## 2.下载Cmake

进入cmake官网：[CMake - Upgrade Your Software Build System](https://cmake.org/)

点击DownLoad

![image-20260811105233174](https://gitee.com/xarzhi/picture/raw/master/img/image-20260811105233174.png)

往下滑找到Binary distributions，我们下载Windows x64 Installer，就是后面的msi文件

- X64 installer：适用于64位电脑的安装包，可一键安装
- X64 ZIP：适用于64位电脑的压缩包，需要解压自行放入位置
- i386 Installer和i386 Zip是适用于32位电脑的

![image-20260811105358188](https://gitee.com/xarzhi/picture/raw/master/img/image-20260811105358188.png)



## 3.安装cmake

下载好msi安装包后直接打开

点击next

![image-20260811105711746](https://gitee.com/xarzhi/picture/raw/master/img/image-20260811105711746.png)

勾选并next

![image-20260811105734455](https://gitee.com/xarzhi/picture/raw/master/img/image-20260811105734455.png)

可以自行勾选是否添加快捷方式，next

![image-20260811105813939](https://gitee.com/xarzhi/picture/raw/master/img/image-20260811105813939.png)

选择安装路径，next，这个路径最好要记住

![image-20260811105854634](https://gitee.com/xarzhi/picture/raw/master/img/image-20260811105854634.png)

点击install

![image-20260811105904733](https://gitee.com/xarzhi/picture/raw/master/img/image-20260811105904733.png)

## 4.验证是否安装成功

随便打开一个终端，或者win+x，再按A，打开powershell，输入如下指令

```bash
cmake --version
```

看到如下输出即安装成功

![image-20260811110932216](https://gitee.com/xarzhi/picture/raw/master/img/image-20260811110932216.png)
